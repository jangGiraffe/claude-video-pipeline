# 클로드 영상편집 정리

> 원본 영상: [코드팩토리 – 클로드 영상편집! 결국 영상 편집까지 점령한 앤트로픽!](https://www.youtube.com/watch?v=LNvBxBYvt28)
> 계기: [Laya 진짜 추천합니다. Jev를 오픈소스로 쓰는법](https://www.youtube.com/watch?v=ZktfWXfOwIY)처럼 **말에 맞춰 애니메이션이 딱딱 바뀌는 영상**은 어떻게 만드는지 궁금해서 찾아봄
> 참고: Laya 영상 제작자가 설명란에 이 영상을 링크해 뒀고 화면 스타일도 같음. 다만 그 영상을 이 방법으로 만들었다고 직접 밝힌 적은 없음 (추정)

---

## 핵심 한 줄

**음성 녹음 → Vrew로 SRT + MP3 추출 → Claude Design 애니메이션 템플릿에 둘 다 업로드 → 수정 반복 → Claude Code + Remotion으로 MP4 렌더링**

말과 화면이 딱 맞는 이유: **SRT 자막 파일에 타임스탬프가 있어서** Claude가 몇 초에 무슨 말을 하는지 정확히 알기 때문이다.

---

## 1. 데모 3종 요약

| # | 만든 것 | 입력 | 제작자 평가 |
|---|---|---|---|
| ① | 자기 서비스 '마진' 소개 영상 | 이미 만든 디자인·프로토타입·발표 자료 + 짧은 프롬프트 | 괜찮지만 프로덕션급에는 부족 |
| ② | 보이스오버 + 애니메이션 영상 (Claude Code 소개) | **음성 MP3 + SRT 자막** | ⭐ **가장 마음에 듦**, 완성도 높음 |
| ③ | 사무실 쇼츠 편집 | 원본 영상 + SRT | 자막 자동 삽입은 좋지만, 직접 쓰지는 않을 것 같음 |

## 2. 공통 시작 방법

1. Claude Design에서 **애니메이션 템플릿**을 고른다.
2. 디자인 시스템을 고르거나, 없으면 Claude 기본 디자인 시스템을 쓴다.
3. 프로젝트 이름을 넣고 **Create from template**을 누르면 바로 생성된다.

## 3. 방법별 상세

### ① 서비스 소개 영상
- 같은 프로젝트 안에 와이어프레임·프로토타입·발표 자료가 이미 있어서 서비스 맥락이 다 들어 있었다.
- 프롬프트: "우리가 제작한 프로토타입을 기반으로 트렌디한 소개 애니메이션 영상을 만들어 줘"
- 처음엔 소리가 없어서 "배경 음악과 효과음도 넣어줘"라고 추가 요청 → 둘 다 들어감.
- **포인트:** 하나의 맥락 안에서 이어서 작업하니까, 대화하며 정한 요소들이 강조 장면으로 그대로 반영됐다.

### ② 보이스오버 애니메이션 ← "말에 맞춰 바뀌는" 방식
- **실패한 시도:** 음성만 올림 → Claude Design이 음성을 받아쓰지 못함. 대신 "어느 부분에 어떤 내용을 넣을지 알려달라"고 되물어 옴.
- **성공한 방법 (Remotion 쓰던 방식 그대로):**
  1. **Vrew**(Whisper 기반 자동 자막 앱)에 음성을 올려 자막을 뽑는다.
  2. 자막은 **SRT**, 음성은 **MP3**로 내보낸다.
  3. 두 파일을 같이 올리고 "이 캡션이랑 MP3를 기반으로 애니메이션 만들어 줘"라고 요청한다.
  4. Claude가 흐름을 파악해 기획안을 내고, 색상 테마를 물어본 뒤 제작한다.
- 결과물은 HTML(웹) 기반이라 테마를 바꾸면 전체 장면이 한 번에 바뀐다 (도쿄나이트, 드라큘라, 터미널 그린 등).

### ③ 쇼츠 편집
- 원본 영상 + SRT를 같이 올림 → 자막·컴포넌트·타임라인이 자동으로 들어감.
- Claude가 SRT로 내용을 이해하고 "이 순간에 강조 타이틀을 넣으면 어떻겠냐"고 먼저 제안함.
- **아쉬운 점**
  - 강조 글자 위치가 어긋남
  - 유튜브가 알아서 붙여 주는 장식까지 영상에 넣어 버림
  - 색상 테마를 바꿔도 원본보다 별로
- 아직 한 번에 "딸깍" 끝나는 수준은 아님.

## 4. 진짜 영상 파일(MP4)로 만들기

- Claude Design 결과물은 **영상이 아니라** 타이밍에 맞춰 움직이는 웹 애니메이션이다. 그래서 스크롤, 텍스트 선택, 컴포넌트별 코멘트가 가능하다.
- MP4가 필요하면 **Handoff to Claude Code** → 명령 복사 → Claude Code에 붙여넣기 → **Remotion** 스킬로 렌더링한다.

## 5. 총평

- 요즘 흔한 "보이스오버 + 애니메이션" 채널들이 원래 Remotion으로 하던 작업을 더 쉽게 할 수 있게 됐다. 예전엔 직접 촬영하는 편집보다 오래 걸렸는데, 이제는 오히려 더 빠르다.
- 1인 기업·스타트업의 서비스 소개 영상이라면 이 정도로 충분하다. 두 개 다 한 번에 뽑은 결과이고, 수정을 반복하면 계속 좋아진다.
- 하이엔드급 결과를 원하면 BGM·효과음 전문가가 필요하다.
- 영상 편집은 외주 단가가 높은 작업이라 비용 절감 효과가 크다.

## 6. 기타 (영상 제작과 무관)

- **토큰 별도 과금:** Claude Design은 별도 인프라에서 돌아가서 따로 과금하는 것으로 봄. 정식 출시되면 Claude 앱에 통합될 거라고 예상.
- **지난 영상 댓글 해명:** 디자이너를 깎아내리려던 게 아니라 흐름을 따라가자는 취지였다며 사과. 앤트로픽은 회사를 사들이는 대신 직접 만들어서 생태계를 넓히고 있다는 분석도 덧붙임.

## 부록: Claude Design 없이 Claude Code로 바로 하는 방법

Remotion이 공식 Claude Code 플러그인과 Agent Skills를 제공한다.

1. Whisper나 Vrew로 음성의 SRT를 뽑는다.
2. Claude Code에 Remotion 스킬을 설치한다.
   ```bash
   npx skills add remotion-dev/skills
   ```
3. "이 SRT 타이밍에 맞춰 장면을 구성해줘"라고 요청한다.
4. 바로 MP4로 렌더링한다.

참고 문서
- [Remotion Docs – Agent Skills](https://www.remotion.dev/docs/ai/skills)
- [Remotion Docs – Claude Code plugin](https://www.remotion.dev/docs/ai/claude-code-plugin)

### 확인하지 못한 부분
Laya 영상에는 오른쪽 아래 페이스캠과 자막이 함께 들어가 있다. 원본 영상은 보이스오버만 쓰는 방식이라, 페이스캠을 어떻게 합성했는지는 설명이 없다.
